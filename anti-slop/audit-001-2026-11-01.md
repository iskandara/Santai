# antislop audit 001, 2026-11-01

Scope: `index.html`, `sizechart.html`. Mode: AFTER (session choice). Method: code inspection plus a computed contrast check. The pages were **not run in a browser**, so layout findings are marked *to verify*. Nothing has been modified.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH (Hard Gate)

1. **R-25 Contrast fails AA across the UI.** `--mid` (#888) on the #f5f5f0 background is 3.24:1 (needs 4.5:1). It carries the ticker, availability text, article counter, "Hold & Rotate" hint (animated to 12% opacity) and every label on the size chart page, all at 8 to 9px. The header links (Size Chart, Instagram, Back) sit at .4 to .45 opacity, which is lower still. In the CMS and password gate, #444 on #0a0a0a is 2.03:1 and #555 on #0a0a0a is 2.66:1.
2. **R-32 / R-39 Keyboard and screen-reader access to the product.**
   - The name, description and size table (`.detail-panel`) only appear on press-and-hold (`.held`). A keyboard user can switch slides with the arrow keys but can never read the product details.
   - The pager dots are 5px `<div>`s with click handlers, not buttons, and are unreachable by Tab.
   - No `:focus-visible` styles exist on the nav buttons or links.
   - Escape does not close the CMS panel or the password gate.
3. **R-39 Pointer, alt text and motion.**
   - `cursor:none` is set on `html`, `body`, the nav buttons and the CMS backdrop, so interactive elements never show `cursor: pointer`. Only touch devices are exempt.
   - Shirt images are created in JS with no `alt`.
   - There is no `prefers-reduced-motion` handling. The ticker runs forever and has no pause control.
   - The page has no `<main>` and no `<h1>`.
4. **R-26 Dead control.** When no Instagram URL is set, the link becomes `href="javascript:void(0)"` at 20% opacity. It is a button that does nothing. Hide it instead.
5. **R-38 / R-36 Invented fallback content.** If Supabase fails and there is no cache, the page shows a made-up product ("The Void Shirt", "SS25 — Drop 01", "Heavyweight 340gsm poplin") as if it were real. Show an honest error state instead. There is also no empty state if the articles table is empty (R-27).
6. **R-03 Mobile / reflow (to verify).**
   - The tap targets are 28px (arrows), 32px (Instagram) and 5px (dots), against a 44px minimum.
   - The layout uses `100vh` with a fixed header and footer, so mobile browser toolbars will probably clip the footer.
   - `html,body{overflow:hidden}` means nothing scrolls in landscape or at 200% zoom.
   - A centred wordmark with absolutely placed side links may collide on narrow phones.
7. **R-02 Em dashes in text.** Visible: `<title>` and footer of `sizechart.html` ("SANTAI — Size Chart — All measurements in cm"), the fallback subtitle, the empty availability marker, and the CMS labels and messages (`index.html` lines 413, 430, 452, 457, 479, 501, 507, 518, 520, 642, 735, 1048). Use commas, colons or periods.
8. **R-37 No design direction file.** There is no `DESIGN.md` and no declared ENERGY / RHYTHM / MOTION dials. The site clearly has a direction (monochrome, mono type, wide tracking), so the fix is cheap: write it down.
9. **R-40 Media and hero.** Shirt `<img>` elements have no `width` or `height`, and the first one has no `fetchpriority="high"`. `sizechart.html` ships `<img src="">`.

## MEDIUM (Purpose-Gate)

10. **R-06 Typography.** Everything is tiny uppercase text with wide tracking (.2 to .38em), plus a monospace UI face. It may well be the brand voice, but the reason needs to be written down, and 8px is too small to read (see 1).
11. **R-19 Animation.** The blinking dot, the ticker, the pulsing hint and three fade-up entrances all run at once. Declare a MOTION dial and a purpose for each.
12. **R-07 Grain overlay.** A noise texture sits over the whole page. It is allowed, but it needs a written identity reason.
13. **R-04 Size Chart icon.** Three horizontal lines read as a menu icon, not a size chart.

## LOW (Quality Locks)

14. **R-31 Reasons not written.** None of the decisions above have a one-line reason. This resolves with finding 8.
15. **C-2 / C-3 No path from product to purchase.** The footer says "Available Now" but there is no buy link, contact or waitlist. This may be intentional, so it is a question for the owner.
16. **R-21 Theme.** Light only, no toggle. This is fine if intentional, but state the reason.
17. **R-23 Placeholder shirt.** The SVG shirt placeholder is acceptable if it is understood as a placeholder, so label it as one.
18. **Markup nit.** `sizechart.html` has `cursor="none"` as an HTML attribute on the back link. It has no effect.

## Outside antislop's scope, but important

- **CMS security.** The password gate runs in the browser, and the default password `santai2025` is in the page source. It is compared client-side and stored in `localStorage`.
- **Exposed write access.** The Supabase anon key is in the source and is used for writes and deletes. Unless Supabase row-level security blocks anonymous writes, anyone can edit or delete your products and uploads with plain `fetch` calls.
- **Unescaped CMS text.** Names, descriptions and the ticker are inserted with `innerHTML` without escaping. Combined with open writes, that allows script injection into your storefront.
- **Fix:** use Supabase Auth plus RLS policies, and escape the output.

# Fix report (findings 1 to 9)

Verified by loading both pages in headless Chromium at 1280x800, 375x667 and 667x375, with mocked Supabase responses. No console errors and no horizontal overflow at any size. Tab order, Escape, Details, Flip, pause, and the error and empty states were exercised.

1. **R-25 Contrast: fixed.** Secondary text `#5c5c58` (6.1:1 on paper). Header links, arrows and dots raised. The detail panel scrim is darker and its text brighter. CMS greys are `#a0a0a0` on `#0a0a0a` (7.6:1). Utility text is now 10px minimum on both pages. The "Hold & Rotate" hint no longer fades.
2. **R-32 Keyboard: fixed.** Details and Flip buttons on every shirt give keyboard and touch users the panel and the back of the shirt. Dots are real buttons. A single focus ring covers every control. Escape closes the CMS and the password gate. The gate takes focus when it opens. Off-screen slides are `inert` so they cannot steal focus. Arrow keys no longer switch slides while typing in the CMS.
3. **R-39 Pointer, alt text and motion: fixed.** Controls show the system pointer, and the dot cursor steps aside over them. Shirt images have `alt`. There is one `<h1>`, `<main>` and a labelled `<nav>`, and product names are `<h2>`. `prefers-reduced-motion` is handled on both pages. A Pause/Play control stops the ticker and the availability blink.
4. **R-26 Instagram link: fixed.** Hidden when no URL is set.
5. **R-38 / R-27 States: fixed.** The invented "Void Shirt" fallback and the "One Shirt. One Season." tagline are gone. A failed load with nothing cached shows an error message with Try again. An empty collection shows "Nothing is on show yet."
6. **R-03 Mobile: fixed and verified.** `dvh` units, 44px targets for arrows, dots, Instagram, Size Chart, Details, Flip and the dots. On phones the dots are hidden (the counter and arrows carry position) and the Size Chart link is icon-only. The Pause control has a 44px hit area but only a 19 to 21px visible height. At 667x375 the layout scales instead of clipping.
7. **R-02 Em dashes: fixed** in visible text on both pages (the code comments that still contain them are not UI text).
8. **R-37 Direction: written** as `DESIGN.md`. It was inferred from the existing code, so please edit anything that isn't what you meant.
9. **R-40 Images: partly fixed.** Shirt images carry a width/height ratio and the first has `fetchpriority="high"`. Logos have dimensions and no longer ship `src=""`. Limit: the shirt images are created by script after the data loads, so the hero cannot be plain HTML without a server-side step.

Not touched: findings 10 to 18, and the security items under "Outside antislop's scope".
